CV 핵심 개념과 모델 스터디 계획

운영계획과 실제 학습할 항목을 두 파트로 정리했습니다.

01

운영계획

준비부터 진행·학습 확인·기록까지

주 1회, 회당 60분(방학 중에는 주 2회) 동안 CV의 핵심 개념과 모델을 함께 공부합니다. 개념이 필요한 이유, 구조와 수식의 의미, 실제 동작 원리를 깊이 이해하는 것을 목표로 합니다. 배운 내용을 자신의 언어와 구조도·수식·코드로 설명하고, 연구에서 설계와 활용을 판단하는 데 연결합니다.

매 세션은 이전 내용 복습·학습 포인트 제시 → Why → What → How → Evidence → 관련 연구와 발전 흐름 → 한계와 연구 활용 → 학습 포인트 확인·공유 기록 순서로 진행합니다. 현장에서 공유 기록의 초안을 남기고, 세션 후 근거와 표현을 보완해 한 페이지로 완성합니다.

01

학습 Level

Level도달 기준적용 기준
L1 · 직관개념이 필요한 이유와 해결하는 문제를 이해하고, 핵심 아이디어를 자신의 언어와 쉬운 예·figure로 설명할 수 있습니다.모든 구성원의 공통 목표
L2 · 동작 원리입력부터 출력까지의 계산 흐름, 구성요소·중요 수식의 역할과 가정, 학습·추론의 차이와 설계 이유를 설명할 수 있습니다.모든 구성원의 기본 도달 기준
L3 · 연구와 구현수식·구현 수준에서 동작을 추적하고, 설계의 근거·한계·대안과 조건이 바뀔 때의 영향을 분석할 수 있습니다.담당자의 준비 기준. 구성원은 자신의 연구와 연결되는 부분부터 심화

필수 / 중요는 학습 우선순위, L1 / L2 / L3는 이해의 깊이를 나타냅니다. 구성원은 L1–L2를 공통 목표로 삼고, 담당자는 동작 원리를 수식·구현과 연결하며 설계 근거·한계·대안까지 준비합니다.

02

세션 준비와 진행

담당자는 아래 여섯 단계에 따라 내용을 준비하고, 세션도 같은 순서로 진행합니다. 목표는 개념이 필요한 이유와 작동 원리를 이해하고, 그 효과와 한계, 연구에서의 활용까지 연결하는 것입니다.

기준 논문이 있는 주제는 해당 논문을 출발점으로 삼습니다. 그 외에는 여러 논문·교재·강의·공식 문서·코드를 참고해 설명을 구성합니다. 각 단계를 펼쳐 세부 준비 안내를 확인할 수 있습니다.

시작 점검 · 5분 (0–5분)

  1. 5분0–5분
    이전 내용 복습 + 학습 포인트 제시

    지난 내용과 이번 학습 목표는 무엇인가?

    • 이전 복습: 지난 공유 기록의 학습 포인트·수정한 설명·남은 질문. 첫 세션은 선수 개념 점검
    • 이번 제시: 주제·목표 Level·학습 포인트
    • 사전 준비: 시작·종료에 같은 문장·항목·순서의 작성지, 설명·수식·도식 작성 공간, 인원수에 맞춰 출력

세션 프레임워크 · 45분 (5–50분)

  1. 5분5–10분

    왜 이 개념이 필요한가?

    • 문제 상황: 해결할 문제·기존 접근의 어려움·구체적인 예

  2. 5분10–15분
    02What아이디어와 원리

    문제를 해결하는 아이디어는 무엇인가?

    • 중심 아이디어: 한 문장 설명·직관적인 그림
    • 개념과 가정: 주요 용어·성립 조건
    • 주요 수식: 기호·각 항의 의미와 아이디어의 연결
  3. 20분15–35분
    03How구조와 동작

    실제로 어떻게 작동하는가?

    • 동작 흐름: 입력 → 계산·변환 → 출력, 구성요소의 역할·연결
    • 학습과 추론: 동작 차이·target·loss·gradient·고정/갱신 파라미터(해당 시)
    • 수식·코드: 차원·연산 위치, 작은 입력 예제의 계산 추적
    • 구조 비교: 구성요소 제거·변경 시의 차이
  4. 5분35–40분
    04Evidence근거와 비교

    효과와 설계 이유를 무엇으로 확인하는가?

    • 대표 근거: 실험·적용 사례·간단한 계산
    • 비교 흐름: 질문 → 비교 대상·변경 요소·고정 조건 → 결과 → 해석
    • 설계 이유: ablation·평가 지표·계산 비용(해당 시)
    • 근거 구분: 자료에서 확인한 사실 / 직접 확인한 결과 / 자신의 해석
  5. 5분40–45분
    05Related Work관련 연구와 발전 흐름

    다른 연구에서는 어떻게 이어지고 달라졌는가?

    • 자료 선정: 주제 이해에 도움이 되는 대표 자료·후속 연구 2–3개
    • 발전 흐름: 유지·변형·대체된 원리와 구조
    • 핵심 차이: 최근 활용 방식·접근별 차이·참고 자료
  6. 5분45–50분
    06Limitations & Applications한계와 연구 활용

    어디까지 유효하며, 우리 연구에는 어떻게 활용할 수 있는가?

    • 조건과 한계: 유용한 상황·가정·실패 조건
    • 적용 제약: 데이터·학습 조건·계산 비용
    • 연구 연결: 활용 지점·추가 확인 질문·후속 실험
    • 근거 구분: 확인된 결과 / 검증 전 활용 아이디어

학습 포인트 확인

시작에 안내한 학습 포인트를 같은 문장·항목·순서로 다시 확인합니다.

  1. 각자 작성 · 5분. 자료나 다른 사람의 답을 보지 않고, 인쇄된 작성지의 모든 항목에 설명·수식·도식으로 답합니다. 막힌 부분도 표시합니다.

각 모델의 구조·수식·학습·구현을 함께 살펴보며, 원리가 밀접하게 연결된 후속 모델은 주요 변화를 비교합니다.

개념 유형 구분

학습 항목 옆의 유형은 해당 항목의 성격과 세션에서 중점적으로 다루는 역할을 나타냅니다. 둘 이상의 관점으로 다루면 모델 · 학습 방법처럼 함께 표기합니다.

유형의미예시
기초 개념텐서 표현과 layer의 동작, 초기화 등 모델 이해의 바탕Tensor / Linear / MLP, Activation / Initialization
기초 연산모델을 구성하는 기본 계산과 변환Convolution / Pooling, Normalization
학습 원리오차를 정의하고 gradient를 계산하는 원리Loss / Backpropagation / Autograd
학습 방법학습 신호·목표·업데이트·전이 방식을 정하는 방법Optimization, Regularization, SimCLR, DINO, MAE
모델 구조여러 모델에서 활용하는 블록 구성과 정보 흐름Transformer
모델구조와 학습 목표를 특정 작업에 맞게 구성한 전체U-Net, CLIP, DETR, DPT, SAM
구성 요소모델 안에서 feature 결합 등 특정 역할을 맡는 구조FPN
구현 기법계산 목표를 유지하며 연산·메모리 사용·실행 흐름을 효율화하는 기법FlashAttention, KV cache
적응 방법사전학습 모델을 새로운 작업이나 데이터 분포에 맞게 조정하는 기법LoRA
분석 방법학습 상태·데이터·모델의 표현과 특성을 관찰하고 평가하는 방법모델 진단, PCA, t-SNE, UMAP
추정 방법관측값에서 잔차와 이상치를 고려해 모델의 파라미터를 구하는 방법Least Squares, RANSAC
생성 모델데이터 분포를 학습해 새 샘플을 만드는 모델 계열과 시스템VAE, GAN, DDPM, Latent Diffusion
생성 방법생성 경로·sampling 절차 또는 이를 위한 학습 목표를 정의하는 방법DDIM, Flow Matching, Rectified Flow

Backbone·Neck·Denoiser·조건 제어는 모델이나 구성 요소의 역할을 덧붙이는 표기입니다. 각각 feature 추출, 다중 해상도 feature 결합, 노이즈 제거를 위한 예측, 조건 입력 반영을 뜻합니다. 예를 들어 ResNet은 모델 · Backbone, FPN은 구성 요소 · Neck, DiT는 모델 · Denoiser, ControlNet은 모델 · 조건 제어로 표시합니다.

유형과 함께 구조·학습 목표·데이터·학습과 추론의 흐름을 살펴보고, 설계의 효과와 한계를 설명할 수 있는 것을 목표로 합니다.

01VAE생성 모델필수

02GAN생성 모델중요

  • 적대적 학습: noise를 데이터로 바꾸는 generator와, 실제·생성 데이터를 구분하는 discriminator의 역할을 이해한다.
  • 두 모델의 갱신: 원 minimax 목표와 generator의 non-saturating 목표를 구분하고, 번갈아 학습할 때의 gradient 흐름을 추적한다.
  • 학습과 추론: 불안정성·mode collapse의 의미를 살펴보고, 생성 시에는 generator를 사용하는 흐름을 확인한다.

03Autoregressive Models생성 모델중요

  • 순차 확률 분해: 앞선 픽셀·토큰을 조건으로 다음 값을 예측하며 이미지의 확률을 구성하는 원리를 이해한다.
  • 대표 모델: PixelCNN의 masked convolution·학습 target을 확인하고, 정답 문맥을 쓰는 학습과 생성 문맥을 쓰는 순차 sampling을 비교한다.
  • 확장과 비용: 순차 추론의 비용을 확인하고, pixel 공간에서 latent token 공간으로 옮기는 연결을 VQ-VAE·VQGAN에서 살펴본다.

04VQ-VAE생성 모델중요

  • 이산 latent: encoder 출력을 codebook의 가까운 벡터로 치환해 decoder에 전달하는 vector quantization을 이해한다.
  • 학습과 gradient: reconstruction·codebook·commitment loss, stop-gradient와 straight-through 추정의 역할을 추적한다.
  • 생성의 두 단계: autoencoder 학습과 code index의 prior 학습을 구분한다. 생성 시 prior → codebook → decoder의 흐름을 연속 latent VAE와 비교한다.

05VQGAN생성 모델중요

  • Tokenizer 학습: encoder·codebook·decoder와 discriminator를 확인하고, reconstruction·perceptual·adversarial 목표의 역할을 구분한다.
  • Prior 학습: tokenizer를 학습한 뒤, 이미지 code의 배열을 예측하는 autoregressive Transformer를 별도로 학습하는 두 단계를 추적한다.
  • 생성과 비교: token sampling → codebook → decoder의 흐름을 확인하고, VQ-VAE와 구조·목표·이미지 표현을 비교한다.

4.2 Diffusion · Flow Matching

06DDPM생성 모델필수

  • Noising과 denoising: forward에서 noise를 더하는 과정과, 학습한 역방향 전이로 noise에서 이미지를 생성하는 과정을 구분한다.
  • 학습 목표: 임의의 timestep에서 noisy 입력을 만들고 ε를 예측하는 목표, noise schedule과 시간 조건을 수식·코드로 연결한다.
  • Sampling: ε 예측으로 역방향 평균을 계산하고 noise를 주입하는 반복 절차를 추적한다. 학습에 쓰는 정답 이미지와 생성 시 입력을 구분한다.

07DDIM생성 방법필수

  • 학습과 sampling 분리: DDPM의 ε-prediction 목표로 학습한 denoiser를 활용하면서 sampling 갱신식을 바꾸는 방법을 이해한다.
  • 갱신식과 경로: 현재 noisy sample → 원본 추정 → 다음 sample의 계산과, η가 추가 noise를 조절하는 역할을 추적한다.
  • 속도와 결과: 같은 초기 noise에서 η=0일 때의 결정적 sampling을 확인하고, timestep 부분집합·sampling 단계 수에 따른 비용과 품질을 비교한다.

08Score-based Generative Models생성 모델필수

  • Score의 의미: noise가 섞인 데이터 분포의 log-density를 입력으로 미분한 gradient를 학습한다는 관점을 이해한다.
  • 원 방법: noise-conditioned score network와 denoising score matching, 여러 noise 수준을 거치는 annealed Langevin sampling을 추적한다.
  • Diffusion과 연결: Gaussian perturbation에서 score와 ε-prediction의 관계를 확인한다. SDE·probability flow ODE 정식화는 후속 심화로 구분한다.

09Latent Diffusion생성 모델필수

  • 학습 단계: 먼저 학습한 autoencoder로 이미지를 압축한 뒤, latent 공간에서 denoiser를 학습하는 두 단계를 구분한다.
  • 조건과 생성: condition·cross-attention·classifier-free guidance의 역할과 noise latent → denoising → 이미지 decoder의 흐름을 추적한다.
  • Autoencoder 비교: KL·VQ regularization 및 perceptual·adversarial reconstruction을 VAE·VQGAN과 연결한다. Stable Diffusion은 후속 활용으로 살펴본다.

10ControlNet모델 · 조건 제어중요

  • 공간 조건: edge·depth·pose 등의 조건을 사전학습 text-to-image diffusion 모델에 추가하는 구조를 이해한다.
  • 학습 구조: 고정된 backbone, trainable branch와 zero-initialized convolution이 연결되는 위치와 gradient 흐름을 추적한다.
  • 설계 이유: 초기에는 원 모델의 출력을 유지하며 조건 제어를 학습하는 원리와, 추론 시 조건의 영향을 확인한다.

11DiT모델 · Denoiser필수

  • Transformer denoiser: 원 DiT에서 autoencoder latent를 patch token으로 바꿔 Transformer로 처리하는 흐름을 이해한다.
  • 조건 주입: timestep·class embedding, adaLN-Zero와 출력 head를 추적하고, ε와 역방향 분산을 예측하는 원 모델을 확인한다.
  • 구조 비교: U-Net denoiser와 비교하고, latent patch 크기·모델 규모·계산량을 바꾼 ablation으로 설계를 검토한다.

12Flow Matching생성 방법필수

  • Probability path: noise 분포와 data 분포를 잇는 경로를 정하고, 그 분포의 변화를 만드는 시간 의존 velocity field를 학습하는 관점을 이해한다.
  • 학습과 생성: conditional path에서 만든 velocity target의 회귀와, 학습한 field를 ODE로 적분하는 sampling을 구분한다.
  • 비교와 연결: 경로 선택과 학습 target을 DDPM의 noise 예측과 비교하고, 다음 Rectified Flow의 직선 보간 목표에 연결한다.

13Rectified Flow생성 방법필수

  • 직선 보간 학습: noise–data pair를 잇는 직선 위에서 두 끝점의 차이를 velocity target으로 회귀하는 방법을 이해한다.
  • 실제 생성 경로: 학습에 쓴 직선 보간과, 학습한 field를 적분해 얻는 ODE 경로가 항상 같거나 직선인 것은 아님을 구분한다.
  • Coupling과 reflow: 생성한 pair로 다시 학습하는 reflow, 경로의 직선성·sampling 단계 수의 관계를 확인하고 Flow Matching과 비교한다.

14Video Diffusion생성 모델중요

  • 시간 축 확장: 대표 논문 한 편을 정해 video tensor·조건 입력·학습 target과 생성 과정을 추적한다.
  • 공간·시간 처리: spatial·temporal 연산 또는 attention이 프레임 내부와 프레임 사이 정보를 결합하는 방식을 이해한다.
  • 평가와 범위: 이미지 품질과 시간적 일관성을 구분해 평가한다. 다른 영상 모델의 구조·조건 방식은 후속 비교로 다룬다.

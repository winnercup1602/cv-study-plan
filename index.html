01

운영계획

준비부터 진행·학습 확인·기록까지

주 1회, 회당 60분(방학 중에는 주 2회) 동안 CV의 핵심 개념과 모델을 함께 공부합니다. 개념이 필요한 이유, 구조와 수식의 의미, 실제 동작 원리를 깊이 이해하는 것을 목표로 합니다. 배운 내용을 자신의 언어와 구조도·수식·코드로 설명하고, 연구에서 설계와 활용을 판단하는 데 연결합니다.

매 세션은 이전 내용 복습·학습 포인트 제시 → Why → What → How → Evidence → 관련 연구와 발전 흐름 → 한계와 연구 활용 → 학습 포인트 확인·공유 기록 순서로 진행합니다. 현장에서 공유 기록의 초안을 남기고, 세션 후 근거와 표현을 보완해 한 페이지로 완성합니다.

01

학습 Level

Level도달 기준적용 기준
L1 · 직관개념이 필요한 이유와 해결하는 문제를 이해하고, 핵심 아이디어를 자신의 언어와 쉬운 예·figure로 설명할 수 있습니다.모든 구성원의 공통 목표
L2 · 동작 원리입력부터 출력까지의 계산 흐름, 구성요소·중요 수식의 역할과 가정, 학습·추론의 차이와 설계 이유를 설명할 수 있습니다.모든 구성원의 기본 도달 기준
L3 · 연구와 구현수식·구현 수준에서 동작을 추적하고, 설계의 근거·한계·대안과 조건이 바뀔 때의 영향을 분석할 수 있습니다.담당자의 준비 기준. 구성원은 자신의 연구와 연결되는 부분부터 심화

필수 / 중요는 학습 우선순위, L1 / L2 / L3는 이해의 깊이를 나타냅니다. 구성원은 L1–L2를 공통 목표로 삼고, 담당자는 동작 원리를 수식·구현과 연결하며 설계 근거·한계·대안까지 준비합니다.

02

세션 준비와 진행

담당자는 아래 여섯 단계에 따라 내용을 준비하고, 세션도 같은 순서로 진행합니다. 목표는 개념이 필요한 이유와 작동 원리를 이해하고, 그 효과와 한계, 연구에서의 활용까지 연결하는 것입니다.

기준 논문이 있는 주제는 해당 논문을 출발점으로 삼습니다. 그 외에는 여러 논문·교재·강의·공식 문서·코드를 참고해 설명을 구성합니다. 각 단계를 펼쳐 세부 준비 안내를 확인할 수 있습니다.

시작 점검 · 5분 (0–5분)

  1. 5분0–5분
    이전 내용 복습 + 학습 포인트 제시

    지난 내용과 이번 학습 목표는 무엇인가?

    • 이전 복습: 지난 공유 기록의 학습 포인트·수정한 설명·남은 질문. 첫 세션은 선수 개념 점검
    • 이번 제시: 주제·목표 Level·학습 포인트
    • 사전 준비: 시작·종료에 같은 문장·항목·순서의 작성지, 설명·수식·도식 작성 공간, 인원수에 맞춰 출력

세션 프레임워크 · 40분 (5–45분)

  1. 5분5–10분
    01Why필요성

    왜 이 개념이 필요한가?

    • 문제 상황: 해결할 문제·기존 접근의 어려움·구체적인 예

  2. 5분10–15분
    02What아이디어와 원리

    문제를 해결하는 아이디어는 무엇인가?

    • 중심 아이디어: 한 문장 설명·직관적인 그림
    • 개념과 가정: 주요 용어·성립 조건
    • 주요 수식: 기호·각 항의 의미와 아이디어의 연결
  3. 15분15–30분
    03How구조와 동작

    실제로 어떻게 작동하는가?

    • 동작 흐름: 입력 → 계산·변환 → 출력, 구성요소의 역할·연결
    • 학습과 추론: 동작 차이·target·loss·gradient·고정/갱신 파라미터(해당 시)
    • 수식·코드: 차원·연산 위치, 작은 입력 예제의 계산 추적
    • 구조 비교: 구성요소 제거·변경 시의 차이
  4. 5분30–35분
    04Evidence근거와 비교

    효과와 설계 이유를 무엇으로 확인하는가?

    • 대표 근거: 실험·적용 사례·간단한 계산
    • 비교 흐름: 질문 → 비교 대상·변경 요소·고정 조건 → 결과 → 해석
    • 설계 이유: ablation·평가 지표·계산 비용(해당 시)
    • 근거 구분: 자료에서 확인한 사실 / 직접 확인한 결과 / 자신의 해석
  5. 5분35–40분
    05Related Work관련 연구와 발전 흐름

    다른 연구에서는 어떻게 이어지고 달라졌는가?

    • 자료 선정: 주제 이해에 도움이 되는 대표 자료·후속 연구 2–3개
    • 발전 흐름: 유지·변형·대체된 원리와 구조
    • 핵심 차이: 최근 활용 방식·접근별 차이·참고 자료
  6. 5분40–45분
    06Limitations & Applications한계와 연구 활용

    어디까지 유효하며, 우리 연구에는 어떻게 활용할 수 있는가?

    • 조건과 한계: 유용한 상황·가정·실패 조건
    • 적용 제약: 데이터·학습 조건·계산 비용
    • 연구 연결: 활용 지점·추가 확인 질문·후속 실험
    • 근거 구분: 확인된 결과 / 검증 전 활용 아이디어

학습 항목

신경망 기초부터 생성 모델까지 · 0–4장

각 모델의 구조·수식·학습·구현을 함께 살펴보며, 원리가 밀접하게 연결된 후속 모델은 주요 변화를 비교합니다.

개념 유형 구분

학습 항목 옆의 유형은 해당 항목의 성격과 세션에서 중점적으로 다루는 역할을 나타냅니다. 둘 이상의 관점으로 다루면 모델 · 학습 방법처럼 함께 표기합니다.

유형의미예시
기초 개념텐서 표현과 layer의 동작, 초기화 등 모델 이해의 바탕Tensor / Linear / MLP, Activation / Initialization
기초 연산모델을 구성하는 기본 계산과 변환Convolution / Pooling, Normalization
학습 원리오차를 정의하고 gradient를 계산하는 원리Loss / Backpropagation / Autograd
학습 방법학습 신호·목표·업데이트·전이 방식을 정하는 방법Optimization, Regularization, SimCLR, DINO, MAE
모델 구조여러 모델에서 활용하는 블록 구성과 정보 흐름Transformer
모델구조와 학습 목표를 특정 작업에 맞게 구성한 전체U-Net, CLIP, DETR, DPT, SAM
구성 요소모델 안에서 feature 결합 등 특정 역할을 맡는 구조FPN
적응 방법사전학습 모델을 새로운 작업에 맞게 조정하는 기법LoRA
분석 방법학습 상태·데이터·모델의 표현과 특성을 관찰하고 평가하는 방법모델 진단, PCA, t-SNE, UMAP
추정 방법관측값에서 잔차와 이상치를 고려해 모델의 파라미터를 구하는 방법Least Squares, RANSAC
생성 모델데이터 분포를 학습해 새 샘플을 만드는 모델 계열과 시스템VAE, GAN, DDPM, Latent Diffusion
생성 방법생성 경로·sampling 절차 또는 이를 위한 학습 목표를 정의하는 방법DDIM, Flow Matching, Rectified Flow

Backbone·Neck·Denoiser·조건 제어는 모델이나 구성 요소의 역할을 덧붙이는 표기입니다. 각각 feature 추출, 다중 해상도 feature 결합, 노이즈 제거를 위한 예측, 조건 입력 반영을 뜻합니다. 예를 들어 ResNet은 모델 · Backbone, FPN은 구성 요소 · Neck, DiT는 모델 · Denoiser, ControlNet은 모델 · 조건 제어로 표시합니다.

유형과 함께 구조·학습 목표·데이터·학습과 추론의 흐름을 살펴보고, 설계의 효과와 한계를 설명할 수 있는 것을 목표로 합니다.

01

CNN 구조와 활용 모델

학습 목표

Convolution·pooling의 연산에서 출발해 CNN 블록과 다중 해상도 feature 구성을 이해하고, 이를 검출·분할의 출력과 학습 구조로 연결한다.

학습 내용 위에서 아래로 권장 학습 순서

01Convolution / Pooling기초 연산필수

  • 공간 연산: locality·weight sharing을 이해하고, kernel·stride·padding·dilation에 따른 출력 shape와 receptive field를 계산한다.
  • 연산 비용: 일반·1×1·group·depthwise convolution의 채널 연결, 파라미터 수와 연산량을 비교한다.
  • Pooling: max·average·global average pooling이 공간 해상도와 정보에 미치는 영향을 확인한다.

02ResNet모델 · Backbone필수

  • Residual learning: plain network의 degradation 문제와, residual branch에 shortcut을 더하는 구조를 연결한다.
  • 블록과 stage: basic block·bottleneck, stage별 해상도·채널 변화, identity·projection shortcut의 조건과 gradient 흐름을 추적한다.
  • 설계 비교: shortcut ablation을 해석하고, pre-activation은 원 ResNet과 구분되는 후속 변형으로 비교한다.

03U-Net모델필수

  • Encoder–decoder: 해상도를 줄이며 문맥을 얻는 경로와, 해상도를 높여 픽셀별 출력을 만드는 경로를 추적한다.
  • Skip connection: encoder feature를 decoder에 concatenation하는 이유와 채널·공간 크기 변화를 확인한다.
  • 해상도 정렬: 원 논문의 up-convolution·crop을 확인하고, interpolation 등 후속 구현의 선택과 구분한다.

04FPN구성 요소 · Neck필수

  • 다중 해상도: backbone의 여러 stage에서 나온 feature를 활용해 크기가 다른 대상을 다루는 이유를 이해한다.
  • Feature fusion: top-down upsampling과 lateral 1×1 convolution, addition 전 해상도·채널 정렬을 추적한다.
  • Neck의 역할: 각 pyramid level의 출력을 확인하고, U-Net의 concatenation과 FPN의 addition을 비교한다.

05Faster R-CNN모델필수

  • Two-stage 검출: 공유 backbone → RPN의 proposal 생성 → RoIPool → 분류·box 보정의 흐름을 추적한다.
  • 학습 신호: anchor·proposal의 정답 할당, objectness·class target, box regression target과 loss를 구분한다.
  • 학습과 추론: proposal 선택·NMS와 두 단계의 역할을 확인하고, 원 논문의 학습 절차와 후속 구현을 구분한다.

06Mask R-CNN모델중요

  • Instance segmentation: Faster R-CNN의 분류·box 예측에 병렬 mask branch를 더하는 구조를 이해한다.
  • 공간 정렬: RoIPool의 좌표 양자화 문제와 RoIAlign의 bilinear sampling을 비교한다.
  • Mask 학습: RoI별 mask target·픽셀별 binary loss·추론 시 class 선택을 연결하고, 원 논문의 ablation으로 설계를 검토한다.

07YOLO모델중요

  • One-stage 검출: 대표 버전 한 편을 정해 backbone·neck·head와 box·class 출력, 정답 할당과 loss를 추적한다.
  • 추론과 비용: 선택한 버전의 후처리를 확인하고, Faster R-CNN과 예측 구조·속도·정확도를 비교한다.
  • 버전 구분: anchor 사용 여부와 NMS 필요 여부는 버전별로 확인한다. 다른 버전의 전체 구조는 별도 심화로 다룬다.
02

Transformer 구조와 활용 모델

학습 목표

Attention·encoder·decoder와 이미지 토큰 구성을 이해하고, 이를 검출·dense prediction·prompt 기반 분할의 구조로 연결한다.

학습 내용 위에서 아래로 권장 학습 순서

01Transformer모델 구조필수

  • Attention: self/cross-attention의 Q·K·V shape, √d_k 스케일링, softmax 축, multi-head 결합과 토큰 수에 따른 계산 비용을 추적한다.
  • 전체 구조: attention·FFN·residual·normalization이 encoder와 decoder에서 연결되는 방식과 causal mask를 설명한다.
  • 순서 정보: sinusoidal positional encoding의 역할을 확인한다. 위치 정보와 순서 의존 mask가 없을 때 self-attention의 permutation equivariance를 이해한다.

02GPT모델중요

  • Decoder-only 구조: 원 GPT의 causal self-attention과 next-token prediction을 입력·target·loss에 연결한다.
  • 학습과 활용: 언어 모델 사전학습과 downstream fine-tuning을 구분하고, 학습의 병렬 계산과 생성의 순차 처리를 비교한다.
  • 후속 확장: KV cache·RoPE는 원 GPT와 구분해 소개한다. 여러 세대의 GPT 전체 구조를 한 세션에 묶지 않는다.

03BERT모델중요

  • Encoder 구조: 원 BERT의 양방향 self-attention과 token·segment·position embedding을 이해한다.
  • 사전학습 목표: masked language modeling·next sentence prediction의 입력과 target을 확인하고, downstream fine-tuning의 head를 구분한다.
  • GPT와 비교: 정보를 볼 수 있는 범위, 학습 목표, 학습 시 입력 구성과 활용 방식의 차이를 설명한다.

04ViT모델 · Backbone필수

  • 이미지 토큰화: 이미지를 patch로 나누고 Linear projection한 뒤, CLS token·learned positional embedding과 함께 encoder에 넣는 흐름을 추적한다.
  • 출력과 해상도: 원 모델의 CLS 기반 분류와 해상도 변경 시 positional embedding 보간을 확인하고, pooling 등 readout 변형과 구분한다.
  • CNN과 비교: 국소 연결·계층 구조 등 inductive bias, receptive field, 데이터 규모와 사전학습의 영향을 비교한다.

05Swin Transformer모델 · Backbone중요

  • 국소 Attention: window attention의 비용을 확인하고, shifted window가 이웃 window 사이의 정보를 연결하는 방식을 이해한다.
  • 계층 구조: patch merging에 따른 해상도·채널 변화, relative position bias와 다중 해상도 출력을 추적한다.
  • 비교: ViT의 전역 attention, CNN의 계층적 feature 구성과 비교해 dense prediction에 활용되는 이유를 설명한다.

06DETR모델필수

  • Set prediction: CNN backbone과 Transformer encoder–decoder, learned object query가 고정 개수의 예측을 만드는 흐름을 이해한다.
  • Matching과 loss: Hungarian matching의 비용과, matching 후 계산하는 class·box loss 및 no-object 처리를 구분한다.
  • 추론 비교: 원 DETR의 NMS 없는 출력을 확인하고, Faster R-CNN·선택한 YOLO 버전의 예측·정답 할당 방식과 비교한다.

07DPT모델필수

  • Dense prediction: ViT 또는 hybrid backbone의 여러 층에서 얻은 토큰을 깊이·분할 출력에 활용하는 전체 흐름을 이해한다.
  • Reassemble과 fusion: 토큰을 공간 feature로 재배열하고 여러 해상도로 변환한 뒤, decoder에서 융합하는 과정을 추적한다.
  • 구조 비교: vanilla ViT의 중간 층이 처음부터 해상도 pyramid인 것은 아님을 확인하고, Swin·FPN·U-Net과 비교한다.

08SAM모델중요

  • Promptable segmentation: 원 SAM의 image encoder·prompt encoder·mask decoder가 이미지와 point·box·mask prompt를 결합하는 흐름을 이해한다.
  • 학습과 추론: 학습 데이터·prompt sampling·mask loss, 모호한 prompt에 대한 복수 mask와 품질 예측, image embedding 재사용을 확인한다.
  • 후속 비교: SAM 2의 streaming memory와 프레임별 prompt·mask 처리를 비교한다. 버전별 전체 구조·평가는 별도 심화로 다룬다.
03

표현 학습과 모델 적응

학습 목표

표현을 얻는 학습 목표와 teacher·target의 역할을 이해하고, pretraining 모델을 활용·적응하는 방법을 구분한다.

학습 내용 위에서 아래로 권장 학습 순서

01Pretraining / Transfer Learning학습 방법필수

  • 학습 단계: pretraining과 downstream task에서 데이터·target·head가 어떻게 달라지는지 구분한다.
  • 적응 범위: frozen feature·linear probing·부분 및 전체 fine-tuning에서 고정·갱신하는 파라미터를 비교한다.
  • 실험 해석: 사전학습 데이터와 학습 조건을 확인하고, 증강·regularization·평가 시 데이터 누수를 기초 원리와 연결한다.

02SimCLR학습 방법필수

  • 학습 쌍: 같은 이미지의 두 augmentation을 positive로, batch의 다른 이미지에서 얻은 view를 negative로 사용하는 구성을 이해한다.
  • 목표와 구조: NT-Xent·temperature, encoder representation과 projection head 출력의 차이를 추적한다.
  • 비교와 주의: 증강·batch 크기의 영향을 확인한다. 여기서 view는 증강한 이미지이며, 다른 카메라에서 촬영한 multi-view와 구분한다.

03CLIP모델필수

  • 이미지–텍스트 정렬: 두 encoder가 paired image·text를 공통 embedding 공간으로 보내는 흐름을 이해한다.
  • 학습 목표: batch 내 정답 pair와 나머지 pair, 정규화된 embedding·temperature·양방향 contrastive loss를 연결한다.
  • Zero-shot 추론: class 이름을 prompt 문장으로 바꿔 text embedding을 만들고, image embedding과의 유사도로 분류하는 과정을 추적한다.

04SigLIP모델 · 학습 방법중요

  • Pairwise 목표: image–text pair의 일치 여부를 sigmoid loss로 학습하는 방식을 이해한다.
  • CLIP과 비교: batch 전체 유사도의 softmax 정규화와 pairwise sigmoid의 차이, positive·negative pair 구성과 bias·scale을 확인한다.
  • 설계 근거: batch 크기·pair 비율·학습 조건을 확인하며 원 논문의 ablation을 읽는다.

05Knowledge distillation학습 방법필수

  • Teacher와 student: teacher의 soft target으로 student를 학습시키는 목적과 temperature의 역할을 이해한다.
  • Loss와 gradient: soft-target loss·hard-label loss의 결합, teacher 고정과 student 업데이트를 수식·코드로 추적한다.
  • 후속 비교: 원 논문의 목표·실험을 기준으로 feature distillation, DINO의 self-distillation·EMA teacher와 차이를 연결한다.

06DINO학습 방법필수

  • 원 DINO: 같은 이미지의 서로 다른 crop에서 teacher·student의 출력 분포를 맞추는 self-distillation을 이해한다.
  • 학습 안정화: multi-crop, EMA teacher·stop-gradient, centering·sharpening과 collapse 방지의 관계를 추적한다.
  • 후속 비교: DINOv2의 image·patch-level 목표와 데이터·학습 레시피, DINOv3의 Gram anchoring을 비교한다. 버전별 전체 구조·목표는 별도 심화로 다룬다.

07MAE학습 방법필수

  • Masked reconstruction: 일부 patch를 가리고, 보이는 patch만 encoder에 넣어 가린 영역의 픽셀을 복원하는 목표를 이해한다.
  • 비대칭 구조: encoder 출력을 원래 위치에 놓고 mask token을 더해 작은 decoder로 보내는 과정과, masked 영역의 pixel 복원 loss를 추적한다.
  • 학습과 전이: pretraining의 decoder와 downstream head를 구분하고, masking 비율·연산량·표현 학습의 관계를 살펴본다.

08SimMIM학습 방법중요

  • 단순한 복원 목표: 가린 위치를 mask token으로 대체한 입력에서 원래 RGB 값을 회귀하는 학습을 이해한다.
  • 구조와 loss: encoder 뒤의 가벼운 prediction head, masked 영역의 L1 loss와 patch·mask 크기를 확인한다.
  • MAE와 비교: mask token의 encoder 통과 여부, decoder·head의 크기, pixel 복원 목표의 차이를 비교한다.

09BEiT학습 방법중요

  • Discrete target: 별도로 사전학습한 visual tokenizer가 만든 discrete token을 가린 위치의 정답으로 사용하는 원 BEiT를 이해한다.
  • 학습 흐름: mask token을 포함한 입력, Transformer·prediction head, token 분류 loss와 tokenizer의 역할을 구분한다.
  • 비교: MAE·SimMIM의 pixel 회귀와 target·head의 차이를 비교한다. 후속 BEiT 버전의 전체 재현은 선택 심화로 둔다.

10LoRA적응 방법중요

  • Low-rank update: 사전학습 가중치는 고정하고, 가중치 변화량을 두 작은 행렬의 곱으로 학습하는 원리를 이해한다.
  • 파라미터와 gradient: 적용 위치·rank·scale, 두 행렬의 초기화와 gradient 흐름을 전체 fine-tuning과 비교한다.
  • 학습과 배포: 가중치에 update를 합치는 조건과 비용을 확인하고, 원 논문의 ablation 및 PEFT 안에서의 역할을 살펴본다.
04

생성 모델

학습 목표

생성 목표, latent 표현, 네트워크 구조와 sampling 과정을 연결해 이해한다.

학습 내용 위에서 아래로 권장 학습 순서

4.1 VAE · GAN · Autoregressive · VQ

01VAE생성 모델필수

  • 잠재변수 모델: encoder가 근사 posterior를, decoder가 관측 데이터의 분포를 나타내는 구조를 이해한다.
  • 학습 목표: ELBO의 reconstruction·KL 항, prior와 posterior, reparameterization을 통한 gradient 흐름을 연결한다.
  • 복원과 생성: 입력을 encoding한 뒤 복원하는 과정과, prior에서 latent를 뽑아 새 샘플을 만드는 과정을 구분한다.

02GAN생성 모델중요

  • 적대적 학습: noise를 데이터로 바꾸는 generator와, 실제·생성 데이터를 구분하는 discriminator의 역할을 이해한다.
  • 두 모델의 갱신: 원 minimax 목표와 generator의 non-saturating 목표를 구분하고, 번갈아 학습할 때의 gradient 흐름을 추적한다.
  • 학습과 추론: 불안정성·mode collapse의 의미를 살펴보고, 생성 시에는 generator를 사용하는 흐름을 확인한다.

03Autoregressive Models생성 모델중요

  • 순차 확률 분해: 앞선 픽셀·토큰을 조건으로 다음 값을 예측하며 이미지의 확률을 구성하는 원리를 이해한다.
  • 대표 모델: PixelCNN의 masked convolution·학습 target을 확인하고, 정답 문맥을 쓰는 학습과 생성 문맥을 쓰는 순차 sampling을 비교한다.
  • 확장과 비용: 순차 추론의 비용을 확인하고, pixel 공간에서 latent token 공간으로 옮기는 연결을 VQ-VAE·VQGAN에서 살펴본다.

04VQ-VAE생성 모델중요

  • 이산 latent: encoder 출력을 codebook의 가까운 벡터로 치환해 decoder에 전달하는 vector quantization을 이해한다.
  • 학습과 gradient: reconstruction·codebook·commitment loss, stop-gradient와 straight-through 추정의 역할을 추적한다.
  • 생성의 두 단계: autoencoder 학습과 code index의 prior 학습을 구분한다. 생성 시 prior → codebook → decoder의 흐름을 연속 latent VAE와 비교한다.

05VQGAN생성 모델중요

  • Tokenizer 학습: encoder·codebook·decoder와 discriminator를 확인하고, reconstruction·perceptual·adversarial 목표의 역할을 구분한다.
  • Prior 학습: tokenizer를 학습한 뒤, 이미지 code의 배열을 예측하는 autoregressive Transformer를 별도로 학습하는 두 단계를 추적한다.
  • 생성과 비교: token sampling → codebook → decoder의 흐름을 확인하고, VQ-VAE와 구조·목표·이미지 표현을 비교한다.

4.2 Diffusion · Flow Matching

06DDPM생성 모델필수

  • Noising과 denoising: forward에서 noise를 더하는 과정과, 학습한 역방향 전이로 noise에서 이미지를 생성하는 과정을 구분한다.
  • 학습 목표: 임의의 timestep에서 noisy 입력을 만들고 ε를 예측하는 목표, noise schedule과 시간 조건을 수식·코드로 연결한다.
  • Sampling: ε 예측으로 역방향 평균을 계산하고 noise를 주입하는 반복 절차를 추적한다. 학습에 쓰는 정답 이미지와 생성 시 입력을 구분한다.

07DDIM생성 방법필수

  • 학습과 sampling 분리: DDPM의 ε-prediction 목표로 학습한 denoiser를 활용하면서 sampling 갱신식을 바꾸는 방법을 이해한다.
  • 갱신식과 경로: 현재 noisy sample → 원본 추정 → 다음 sample의 계산과, η가 추가 noise를 조절하는 역할을 추적한다.
  • 속도와 결과: 같은 초기 noise에서 η=0일 때의 결정적 sampling을 확인하고, timestep 부분집합·sampling 단계 수에 따른 비용과 품질을 비교한다.

08Score-based Generative Models생성 모델필수

  • Score의 의미: noise가 섞인 데이터 분포의 log-density를 입력으로 미분한 gradient를 학습한다는 관점을 이해한다.
  • 원 방법: noise-conditioned score network와 denoising score matching, 여러 noise 수준을 거치는 annealed Langevin sampling을 추적한다.
  • Diffusion과 연결: Gaussian perturbation에서 score와 ε-prediction의 관계를 확인한다. SDE·probability flow ODE 정식화는 후속 심화로 구분한다.

09Latent Diffusion생성 모델필수

  • 학습 단계: 먼저 학습한 autoencoder로 이미지를 압축한 뒤, latent 공간에서 denoiser를 학습하는 두 단계를 구분한다.
  • 조건과 생성: condition·cross-attention·classifier-free guidance의 역할과 noise latent → denoising → 이미지 decoder의 흐름을 추적한다.
  • Autoencoder 비교: KL·VQ regularization 및 perceptual·adversarial reconstruction을 VAE·VQGAN과 연결한다. Stable Diffusion은 후속 활용으로 살펴본다.

10ControlNet모델 · 조건 제어중요

  • 공간 조건: edge·depth·pose 등의 조건을 사전학습 text-to-image diffusion 모델에 추가하는 구조를 이해한다.
  • 학습 구조: 고정된 backbone, trainable branch와 zero-initialized convolution이 연결되는 위치와 gradient 흐름을 추적한다.
  • 설계 이유: 초기에는 원 모델의 출력을 유지하며 조건 제어를 학습하는 원리와, 추론 시 조건의 영향을 확인한다.

11DiT모델 · Denoiser필수

  • Transformer denoiser: 원 DiT에서 autoencoder latent를 patch token으로 바꿔 Transformer로 처리하는 흐름을 이해한다.
  • 조건 주입: timestep·class embedding, adaLN-Zero와 출력 head를 추적하고, ε와 역방향 분산을 예측하는 원 모델을 확인한다.
  • 구조 비교: U-Net denoiser와 비교하고, latent patch 크기·모델 규모·계산량을 바꾼 ablation으로 설계를 검토한다.

12Flow Matching생성 방법필수

  • Probability path: noise 분포와 data 분포를 잇는 경로를 정하고, 그 분포의 변화를 만드는 시간 의존 velocity field를 학습하는 관점을 이해한다.
  • 학습과 생성: conditional path에서 만든 velocity target의 회귀와, 학습한 field를 ODE로 적분하는 sampling을 구분한다.
  • 비교와 연결: 경로 선택과 학습 target을 DDPM의 noise 예측과 비교하고, 다음 Rectified Flow의 직선 보간 목표에 연결한다.

13Rectified Flow생성 방법필수

  • 직선 보간 학습: noise–data pair를 잇는 직선 위에서 두 끝점의 차이를 velocity target으로 회귀하는 방법을 이해한다.
  • 실제 생성 경로: 학습에 쓴 직선 보간과, 학습한 field를 적분해 얻는 ODE 경로가 항상 같거나 직선인 것은 아님을 구분한다.
  • Coupling과 reflow: 생성한 pair로 다시 학습하는 reflow, 경로의 직선성·sampling 단계 수의 관계를 확인하고 Flow Matching과 비교한다.

14Video Diffusion생성 모델중요

  • 시간 축 확장: 대표 논문 한 편을 정해 video tensor·조건 입력·학습 target과 생성 과정을 추적한다.
  • 공간·시간 처리: spatial·temporal 연산 또는 attention이 프레임 내부와 프레임 사이 정보를 결합하는 방식을 이해한다.
  • 평가와 범위: 이미지 품질과 시간적 일관성을 구분해 평가한다. 다른 영상 모델의 구조·조건 방식은 후속 비교로 다룬다.
